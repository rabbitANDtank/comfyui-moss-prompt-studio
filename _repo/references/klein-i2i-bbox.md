# Klein 编辑标注格式 i2i_bbox（中文速查）

来源：用户提供的 Klein 系统提示词 `system_prompts.json → i2i_bbox`（原为英文，此处摘录要点并译）。
用途：**MOSS-Image 不支持图像编辑**，要"框内改字/换物/挪位"，就走 Klein。本 skill 负责把 layout 几何换成 Klein 能吃的标注——画布导出页签「Klein 编辑稿」就是这一步的结果。

## 一、输出形态

**一行**：先是英文指令段，一个空格，然后是**一个 JSON 数组**。不要别的东西。

## 二、指令段怎么写

- 英文，**指令口吻**：`Change the …` / `Remove the …`；从零新建时用 `Create a photograph of …`。
- 不要旁观者口吻，不要和目标图做比较。
- 每个涉及的对象/人物/文字块，**第一次提到时用尖括号带表 id**：`remove the delivery van <van_1>`。
  - 每个 id **恰好出现一次**，不能引用表里没有的 id。
  - 内容取自参考图时，连参考图 token 一起写：`the cup <cup_1> from <ref_image_1>`。
- **终态写进指令段**（新颜色、引号里的新文字、姿势、程度）；静态外观写进 `desc`；**指令段里不写坐标**。
- 编辑类指令**结尾加一句**：其余一切与源图保持一致。

## 三、表格结构

每行：`{"id","from","src_bbox","tgt_bbox","desc"}`

| 键 | 含义 |
|---|---|
| `id` | 小写类名词 + 序号（`person_1`、`cup_2`），先左到右再上到下；文字块是 `En_Text_1` 这类；全局唯一 |
| `from` | `ref_image_N` = 来自第 N 张参考图；`target` = 本次新造的内容 |
| `src_bbox` | 该对象在 from 图里的框；`target` 行填 **null** |
| `tgt_bbox` | 该对象在结果图里的框；**被删除**的填 **null**；移动改大小的两栏都填 |
| `desc` | 一段英文，写该对象**静态外观**，以身份开头；人物写得最细（族裔、性别、年龄段、肤色、发型、面部、服装、配饰、姿态、表情）；文字行**逐字引原文** |

可选：`src_bbox_1stage` / `tgt_bbox_1stage`（第一遍粗估框）。

## 四、坐标口径（与 MOSS 不同，必须换算）

- 顺序 `[y_min, x_min, y_max, x_max]`
- 整数，**0–1000**
- **左上原点**（MOSS 编译稿是中心原点 → 要先加 `W/2`、`H/2`）
- 紧贴对象；**文字块四周留 5–15 单位**余量

换算表：

| 来源 | 原顺序/原点 | 换算到 Klein |
|---|---|---|
| MOSS 草稿 `abs`/`xyxy` | `[x1,y1,x2,y2]` 左上像素 | `x/W*1000`、`y/H*1000`，再排成 `[y,x,y,x]` |
| MOSS 编译稿 `abs_centralized`/`yxyx` | `[y1,x1,y2,x2]` 中心像素 | 先 `+W/2`、`+H/2` 转左上像素，再同上 |
| Klein 输出 | `[y,x,y,x]` 0–1000 左上 | —— |

`scripts/to_klein.py` 与画布的导出页签都实现了上述换算，并对文字行自动加余量。

## 五、其他硬要求

- 只写**已定事实**：源图看得见的、指令要求的、或实现它必须的具体默认值。
- 必须落定：改的是一个实例/一类全部/几个；所有"程度"落到具体数值；写上可见的连带影响。
- 新增物体按真实世界尺寸；放大要说明排除了哪些邻居；扩图要保持源图完整、同一媒介续画。
- 指令没涉及的一切，都与源图一致。
