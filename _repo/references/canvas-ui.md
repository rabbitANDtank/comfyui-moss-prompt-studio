# 画布操作手册

## 一、界面分区

```
┌ 顶栏：画布尺寸 · 加框 · 删除 · 撤销/重做 · 层级 ↑↓ · 导出语言 · 导出 ─┐
├───────────────────────────┬──────────────────┤
│ 整张图是什么（summary）    │ 图层（谁盖住谁）  │
│   caption EN / 中文参考    │                  │
│   meta / canvas / palette  ├──────────────────┤
├───────────────────────────┤ 字段（选中那块）  │
│ 画布：框上直接写内容       │  label / text     │
│                           │  caption EN / 中文│
│                           │  bbox / 前后关系   │
└───────────────────────────┴──────────────────┘
```

**上方管整体，下方每个框管局部。** 这是这张 JSON 的全部结构，没有第三个层次。

## 二、字段中英对照

### summary（整张图是什么）

| 字段 | 中文 | 管什么 | 例子 |
|---|---|---|---|
| `caption` | 整图描述 | 构图、主体、场景、材质、光、风格 | `A warm still-life poster … soft window light from the left.` |
| `meta` | 体裁标签 | 这是什么东西 | `["product poster", "still-life photography"]` |
| `canvas` | 画布结构 | `single` 一整幅 / `multi_panel` 多格 / `collage` 拼贴 | `single` |
| `palette` | 主配色 | 全局色倾向 | `["#F4EFE6", "#4A3327"]` |

**palette 可以直接点**：字段下面是一排色块，点色块取色、`＋` 加一个、`×` 删一个，
上面的文本框与色块双向同步，手输十六进制也行。

### items[]（图里每一块）

| 字段 | 中文 | 管什么 | 例子 |
|---|---|---|---|
| `label` | 类型 | `object` 物体 / `character` 人物 / `text` 文字 | `text` |
| `caption` | 外观描述 | 这块**看起来**什么样：外形、材质、颜色、字体、笔画 | `A bone-white ceramic cup with a matte glaze …` |
| `caption_zh` | 中文参考 | 只给编辑器用，**不导出** | `骨白陶瓷杯，哑光釉面…` |
| `bbox` | 位置框 | `[x1,y1,x2,y2]` 像素、左上原点 | `[420, 900, 860, 1290]` |
| `text` | 文字内容 | 文字块**逐字**要画出来的内容，换行写 `\n` | `晨间手冲` |
| `tags` | 标签 | 可选 | `["ceramic", "tableware"]` |
| `palette` | 本块配色 | 可选 | `["#F4EFE6"]` |

**最容易搞错的一条**：想让它写「晨间手冲」，字要写进 `text`；只写进 `caption` 的话，模型只会"知道有这么一句话"，不会逐字画。

**中文参考不空着**：没翻译时，编辑器会自动把英文原文带进「中文参考」输入框，你直接在上面改成中文即可。
这个回填**不会**被当成真翻译写回数据，只有你手动改过才会存下来。

## 二·五、底图

`--image` 给的图会**内嵌进 HTML**（装了 Pillow 就压到长边 1800 的 JPEG，没装就原样内嵌），
所以这份 HTML 拷给别人、换台电脑都看得到。画布上方有说明条标注底图文件名。
图像编辑任务里，这张底图就是 `<Picture 1>` 那张待修改的图。

## 三、框上显示的是什么

- **文字块**：`text` 原文（真实换行）+ 中文外观描述；选中/悬浮时再加英文描述。
- **物体块**：中文外观描述；选中/悬浮时展开成三行并显示英文。
- **十字虚线框**：铺满全画布的背景元素，不挡住别人的点击，选它请点右侧图层列表。
- 框太小（宽 < 210 或高 < 88 画布像素）只显示编号和类型，避免字压字。

## 四、画布尺寸：比例 + 百万像素

顶栏两个下拉：

| 下拉 | 取值 |
|---|---|
| 比例 | 1:1 / 4:3 / 3:4 / 3:2 / 2:3 / 16:9 / 9:16 / **21:9** / 9:21 / 2:1 / 1:2 / 1:8（条漫） |
| MP | 1 / 1.5 / 2 / 4 百万像素 |

选完立刻算出分辨率并**等比外扩**：`H = √(px × 纵比 ÷ 横比)`，宽高各自取整到 **16 的倍数**，
所有框等比缩放跟着走。只选比例不选 MP 时，保留当前总像素只换比例。手改宽高同样等比缩放。
整步可撤销（Ctrl+Z）。

## 四·五、前后关系（闸门，不是按钮）

**JSON 没有 z 字段**，官方只说"多个 item 可以共享或重叠一个框"。所以：

- 数组顺序只是编辑器里的图层，**不是**模型能识别的机制；
- 真正生效的是 caption 里的句子。

**这里不做一键按钮**（试过会翻车：自动取的名字在多人构图里退化成同一个模糊指代，还会自相矛盾），
改成闸门：

1. 右侧「重叠与前后」列出每一对重叠 + 重叠区间（面积大的在前）
   ——铺满画布的底、整块包住另一块的，都已排除
   ——已写遮挡句显示 ✓，没写显示 ?
2. 导出面板会提醒「N 对框重叠且没写前后关系」
3. 点 **「复制『前后关系询问单』」** → 贴给 skill → 由它定前后、写句子、把草稿交回来

写句子的规矩：指代用**方位短语**（`the bust above it` / `the bust on its right` / `the central bust`）；
半身像不说 `lower body`；一句话只讲一件事。

## 五、快捷键

| 键 | 作用 |
|---|---|
| `Del` / `Backspace` | 删除选中框 |
| 方向键 / `Shift`+方向键 | 移动 1px / 10px |
| `Ctrl+Z` / `Ctrl+Shift+Z` | 撤销 / 重做 |
| `Ctrl+S` | 打开导出面板 |
| 拖框体 / 拖四角 | 移动 / 缩放 |
| 双击框 | 跳到对应字段 |

## 六、导出前会检查什么

**错误（不修就不能编译）**
- 画布宽高不是 16 的正整数倍
- `summary.caption` 为空
- 某个 item 的 caption 为空
- `text` 类型却没有 `text`
- 框宽高非正 / 超出画布

**提醒（能编译，但可能不好看）**
- 文字块框高 < 24px（字会很小）
- 单块文字 > 200 字（容易糊）
- 元素 > 24 个（文字块越碎越难渲染）
- 没有铺满全画布的背景元素（背景会被模型自己编）

## 六点五、Klein 页签的任务闸门与端口映射

**闸门**：Klein 页签顶部要先选「文生图 / 图像编辑」，默认停在**文生图**。
文生图时该页签不出内容（MOSS 提示词就够了）；只有改已有图才切成「图像编辑」。
**分不清是哪种任务时，先别导出，回去问清楚。**

**逐行来源**：切成「图像编辑」后，每一块都要选它来自哪张图——
`target`＝本次新造（不接参考图），`ref_image_N`＝来自第 N+1 张参考图。

**端口映射表（提交前逐行核对）**：

| 提示词引用 | 表格 from 值 | 该接的 ComfyUI 端口 | 这个端口实际接哪张图 |
|---|---|---|---|
| `<Picture 1>` | `ref_image_0` | `ref_images.ref_image_0` | 自己填 |
| `<Picture 2>` | `ref_image_1` | `ref_images.ref_image_1` | 自己填 |

**`<Picture N>` 从 1 数，`ref_image_N` 从 0 数，两边差 1** —— 这是最容易接错的地方，这张表就是防这个的。
最后一列空着不许提交。

## 七、常见问题

**Q：改完画布尺寸，框全乱了？**
A：坐标是绝对像素，改尺寸不会等比缩放。先把尺寸定下来再摆框，或者手动改数字框。

**Q：中文写在哪？**
A：两处都可写。「中文参考」默认不导出；顶栏切到「导出用中文」后，导出时用中文 caption，英文自动兜底。

**Q：导出的 JSON 能直接贴吗？**
A：能。MOSS 提示词那个页签是单行 JSON，贴进 `CLIPTextEncode` 的正向框即可；负向留空。
